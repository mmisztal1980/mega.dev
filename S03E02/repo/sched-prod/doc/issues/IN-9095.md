## Intent
The 'today' button is missing from week view on phones. Show it there, as on larger screens.

## Acceptance
- Given week view on a 375 px wide screen, when it renders, then the 'today' button is visible.
- Given that button, when it is tapped, then week view jumps to the current week in the viewer's zone.
- Given week view on a desktop screen, when it renders, then the 'today' button does not move or change.

## Boundaries
- Must not change the desktop layout.

Allowed by AUT-1 (bug fixes and small features inside the specs, with a test that shows the change).
