## Intent
The booking page shows only the start time of each slot. Show its end time next to it (a Slot has a start and an end, specs/product.md), in the viewer's zone (PRD-2).

## Acceptance
- Given a slot from 10:00 to 11:00, when the booking page shows it, then it reads 10:00–11:00.
- Given a viewer in another zone, when the booking page shows the slot, then start and end are both in the viewer's zone.
- Given the booking page, when the end time is added, then the start time it shows now is not removed or changed.

## Boundaries
- Must not change how slots are stored.

Allowed by AUT-1 (new columns, filters or fields that add to what is there and take nothing away).

Request (mail): "Our booking page shows only the start time of each class. Could it show when the class ends as well?"
Request IN-3740 (desk): "the slot list on the booking page only shows when a slot starts. Customer wants the end time too."
