## Intent
The CSV export breaks when a client name has a comma in it: the columns shift by one from there. Quote fields that hold a comma, a quote or a line break (RFC 4180), so every row keeps its columns.

## Acceptance
- Given a client named "Smith, Jones & Co", when the export is generated, then the row has the same number of columns as the header and the name reads back whole.
- Given a name with a double quote, when the export is generated, then the quote is doubled inside a quoted field and reads back whole.
- Given a row with no comma, quote or line break, when the export is generated, then it is not changed.

## Boundaries
- Must not add, remove, rename or reorder columns (PRD-3).
- Must not change the date or time format.

Allowed by AUT-1 (bug fixes and small features inside the specs, with a test that shows the change).
