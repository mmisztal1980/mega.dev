## Intent
A front desk needs a compact week view that fits a whole day on one screen. Build it as a denser layout from the spacing scale (DES-3), as an option next to the current view. It waits for SCHED-4468: until margins are on the spacing scale, a denser layout cannot come from it.

## Acceptance
- Given a team member who turns on the compact view, when week view renders on a 1080 px tall screen, then 08:00 to 20:00 fits without scrolling.
- Given the compact view, when its CSS is read, then every spacing value is a spacing-scale token, and no font size is below the type scale (DES-1).
- Given a team member who does not turn it on, when week view renders, then it does not change.

## Boundaries
- Must not replace the current week view.
- Must not add spacing values outside the 4 px scale.

Allowed by AUT-1 (a denser layout built on the spacing scale (DES-3)).
