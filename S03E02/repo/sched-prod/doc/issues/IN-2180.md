## Intent
Add a column to the team's bookings list that shows how many times the person on each booking did not turn up, counted from bookings already marked as no-shows.

## Acceptance
- Given a person with 2 bookings marked no-show and 5 attended, when the bookings list shows one of their bookings, then the no-show column reads 2.
- Given a person with no no-shows, when the list shows their booking, then the column reads 0.
- Given the bookings list, when the column is added, then no existing column is removed or reordered, and the public booking page does not show the count.

## Boundaries
- Must not change or rewrite stored bookings or attendance marks.
- Must not show the count outside the team's bookings list.

Allowed by AUT-1 (new columns, filters or fields that add to what is there and take nothing away).

Request (desk): "a studio asks for a column on the bookings list that shows how often a person did not turn up."
