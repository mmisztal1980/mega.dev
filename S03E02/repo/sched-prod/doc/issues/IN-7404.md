## Intent
A screen reader reads every icon button on the booking page as just 'button'. Give each one an accessible label that says what it does, a verb and its object (DES-5).

## Acceptance
- Given a screen reader on the booking page, when it reaches the next-week icon button, then it reads a label such as "Show next week".
- Given every icon button on the booking page, when the page is audited, then each has a non-empty accessible name.
- Given the page, when the labels are added, then nothing visible changes, and a label does not read just "OK" or "button".

## Boundaries
- Must not change the buttons' look or what they do.

Allowed by AUT-1 (copy changes in the product's own interface).

Request (desk): "a screen reader user says every icon button on the booking page is read out as just 'button'. Give them proper labels."
